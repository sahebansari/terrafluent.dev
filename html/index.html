TerraFluent.Html.Reporting

Print-ready HTML reports, no PDF engine required

Fixed-page, paginated reports as self-contained HTML/CSS — view them in any browser, print them to PDF, ship them from any .NET runtime.

{% include install-row.html package="TerraFluent.Html.Reporting" %}

A fluent API for paginated documents

{% highlight csharp %} var report = ReportDocument.Create(PageSize.A4, PageOrientation.Portrait) .SetMargins(40, 40, 60, 60) .Header(h => h.AddText("Monthly Sales Report").AlignCenter().Bold()) .Footer(f => f.AddPageNumber("Page {page} of {totalPages}")) .Content(c => { c.AddHeading("Sales Summary", HeadingLevel.H1); c.AddTable(t => { t.AddColumns("Product", "Qty", "Revenue"); t.AddRow("Widget A", "120", "$2,400"); }); }) .Build(); {% endhighlight %}

Highlights

  • Fixed page geometry — A4, Letter, Legal, portrait/landscape, and custom sizes.
  • Repeating headers & footers — including page-number templates.
  • Rich content elements — paragraphs, headings, images, tables, lists, rules, spacers, page breaks, raw HTML.
  • Native Code 128 barcodes — no external libraries or services.
  • Advanced pagination — line-level splitting, table row pagination, numbered-list continuation.
  • Streaming APIs — async file rendering for large reports.
  • Extensible — custom elements, renderers, and ITextMeasurer for pixel-perfect layout.

Compatibility

Targets netstandard2.0 (works on .NET Framework 4.6.1+ and .NET Core 2.0+) with a dedicated net10.0 build. Zero-dependency core. MIT licensed.
