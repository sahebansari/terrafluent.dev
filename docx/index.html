TerraFluent.Docx.Reporting

Native Word documents, no Word required

Writes Open XML packages directly — real .docx invoices, proposals, policy documents, and branded templates from any .NET runtime, on any OS.

{% include install-row.html package="TerraFluent.Docx.Reporting" %}

A fluent API for Word documents

{% highlight csharp %} Document.Create(doc => { doc.Page(page => { page.Header().Text("Quarterly Proposal"); page.Content().H1("Executive Summary"); page.Content().Text("Prepared for Contoso Ltd."); }); }).PublishDocx("proposal.docx"); {% endhighlight %}

Highlights

  • Direct Open XML generation — no Word installation, no COM automation; output validated with the Open XML SDK.
  • Full document styling — tables, headers, footers, page margins, columns, text formatting.
  • Charts — legends, axis titles, data labels, stacked bars, custom sizing.
  • Templates — placeholder replacement for company-branded documents.
  • Document protection — password-protected editing restrictions.
  • Vector Code 128 barcodes, auto-numbered captions, and table of figures.
  • Images — with wrapping and cropping options.

Compatibility

Targets netstandard2.0 (works on .NET Framework 4.6.1+ and .NET Core 2.0+) with a dedicated net10.0 build. Runs on Windows, Linux, and macOS. MIT licensed.
